# mock-code-2

Чистый проект для приёмки полного пути редактора: подключение репозитория →
правка → удаление экрана → пул-реквест.

Устройство намеренно простое и узнаваемое:

- экраны — `src/pages/Screen-<name>/Screen.tsx`;
- адреса — `src/routes.tsx` (react-router);
- токены темы — `src/shared/theme/tokens.css`;
- записи коллекций — `src/data/`.

**Папки `.ude/` здесь нет специально.** Редактор заводит её сам при первом
жесте — и то, что он это делает правильно, входит в предмет проверки.
